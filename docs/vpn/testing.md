# 试用与验收：7 天实测流程

不要因为别人说“稳定”就年付。用一个月的小额订阅，按下面流程测试 7 天，再决定是否续费。

## 试用前

1. 只买 **月付**，不买年付/终身；
2. 确认退款/取消规则；
3. 用独立的 Clash Verge profile，避免污染主配置；
4. 记录购买日期、到期时间、订单号；
5. 不要把订阅链接发到公开群或仓库。

## Day 1：能连、能导入、能分流

- 导入 Clash/Mihomo 订阅；
- 检查配置是否能被 Clash Verge 正常解析；
- 选择节点，开系统代理；
- 访问几个常用网站；
- 看“连接”页是否命中正确规则；
- 试一次 TUN（如果服务商声称支持 UDP）。

验收：

- 订阅导入无报错；
- 节点能连；
- 规则没有明显错误；
- DNS 没有导致常用网站打不开。

## Day 2：晚高峰

在 20:00–23:00 测试：

```bash
# 延迟和丢包
ping -c 20 <节点域名或 IP>

# 路由
mtr -rw -c 20 <节点域名或 IP>

# 下载速度（Cloudflare 测试文件）
curl -o /dev/null -w 'speed=%{speed_download} bytes/s\n' \
  'https://speed.cloudflare.com/__down?bytes=100000000'
```

记录：

- 平均延迟；
- 丢包率；
- 下载速度；
- 是否断流；
- 视频/会议是否卡顿。

如果晚高峰丢包明显、速度骤降，说明可能超售。

## Day 3：DNS、IP 与泄漏

- 浏览器访问 IP 查询页，确认出口 IP 与节点地区一致；
- 用 DNS 泄漏测试网站检查 DNS 解析器；
- 确认没有同时走本地 DNS 和代理 DNS 的异常组合；
- 检查 WebRTC 是否暴露真实 IP（如果使用浏览器）；
- 对比开/关代理时的结果。

命令行：

```bash
# 出口 IP
curl -s https://api.ipify.org

# DNS 解析
nslookup www.example.com
```

注意：机场没有“匿名保证”，DNS/WebRTC 检查只是确认配置没有明显泄漏，不等于匿名。

## Day 4：实际用途

按你的真实场景测试：

| 场景 | 测试 |
| --- | --- |
| 浏览/办公 | 常用网站、视频会议、大文件 |
| AI/开发 | API 调用、Git、npm/pip、长连接 |
| 流媒体 | 你实际使用的服务是否稳定 |
| 游戏/语音 | UDP、延迟、丢包、TUN |
| 移动/多设备 | 设备数限制、切换网络后是否恢复 |

不要只测试“能打开首页”，要测试登录、上传、长连接和高峰时段。

## Day 5：TUN 与 UDP

如果服务商声称支持游戏/UDP：

1. 安装服务模式；
2. 开 TUN；
3. 测试游戏/语音；
4. 观察延迟、丢包、断线；
5. 关闭 TUN，确认系统网络恢复。

如果 TUN 下网络异常，先排除服务模式、其他 VPN、DNS 和路由冲突，再判断是服务商问题。

## Day 6：客服与退款

提一个具体问题，例如：

```text
晚高峰某地区节点丢包 10% 以上，能否换线路或退款？
```

记录：

- 首次响应时间；
- 是否模板回复；
- 是否能解决问题；
- 退款是否按条款执行；
- 取消订阅是否方便。

客服质量往往比宣传页更能反映长期可靠性。

## Day 7：决策

建议的淘汰线：

- 晚高峰丢包持续 > 5%；
- 常用场景频繁断流；
- 客服 48 小时无有效回复；
- 退款拖延或设置障碍；
- 配置不兼容 Clash/Mihomo；
- 出现一票否决项（见[评估清单](criteria.md)）。

如果只是“偶尔慢”，先确认是不是本地网络/节点选择问题，再决定。

## 配置安全检查

导入订阅后，检查：

- 是否只有标准 Clash/Mihomo 字段；
- 是否包含你不理解的脚本/扩展；
- DNS 是否指向可疑服务器；
- 规则是否把敏感流量导向异常节点；
- 是否有奇怪的 `hosts` 覆盖；
- 订阅 token 是否出现在公开日志/截图里。

Clash Verge Rev 的“扩展脚本”可以执行 JavaScript；不要导入来源不明的脚本。

## 付款与退出

- 优先月付；
- 确认退款窗口；
- 取消订阅/删除账号的流程；
- 确认订阅到期后不会自动续费；
- 保留订单和退款记录；
- 不再使用时删除订阅配置和本地缓存。

## 合规提醒

在购买/使用前确认当地法律、组织政策和服务条款。本文只讨论技术评估，不构成购买或法律建议。
