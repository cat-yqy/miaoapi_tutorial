# 快速上手：订阅、节点与代理

这一页把最短可用路径走一遍：导入订阅 → 选择配置 → 选择节点 → 开启代理 → 验证。

## 1. 导入订阅

打开 **订阅（Profiles）** 页，点击右上角 `+`，选择 **远程订阅 / Remote**。

填写：

| 字段 | 说明 |
| --- | --- |
| 名称 | 自己识别用，例如 `main` |
| URL | 你的订阅链接 |
| 自动更新 | 建议开启，间隔按服务商建议，常见 6–24 小时 |
| User-Agent | 可选；有些服务商按 UA 下发不同配置 |

保存后，Clash Verge Rev 会下载配置并生成一个 profile 卡片。

!!! warning "订阅链接是凭据"
    订阅链接通常包含你的账号 token。不要发到公开群、截图或仓库里。泄露后到服务商后台重置订阅。

### 导入失败怎么办

- `client error(Connect)`：换用“订阅链接配置”或 URL Schemes 再试；
- `401`：订阅过期、token 错误或被服务商封禁；
- `无效的证书`：确认网络环境没有拦截 HTTPS；只有在明确知道风险时才勾选“允许无效证书”；
- 链接打不开：先在浏览器里测试订阅 URL 是否能下载 YAML。

## 2. 选择配置

订阅页会显示多个 profile。点击卡片选中要使用的配置。

右键卡片通常可以：

- 更新；
- 编辑规则；
- 编辑节点；
- 编辑扩展配置；
- 编辑扩展脚本；
- 复制/删除。

先只保留一个主配置，确认可用后再做多订阅合并，排错会简单很多。

## 3. 选择节点

打开 **代理（Proxies）** 页。

你会看到代理组，例如：

- 手动选择 / Select；
- 自动选择 / URL-Test；
- 故障转移 / Fallback；
- 流媒体、AI、Telegram 等分组（取决于订阅）。

操作：

1. 先点“测试延迟”；
2. 选一个延迟低、稳定的节点；
3. 如果组是 `url-test`，它会自动选延迟最低的节点；
4. 如果组是 `select`，需要你手动点选。

!!! tip "不要只看延迟"
    延迟低不等于带宽高或稳定。下载、视频、长时间连接更要看实际体验和丢包。

## 4. 选择路由模式

在代理页或顶部模式选择器里选：

- **规则（Rule）**：推荐，按规则分流；
- **全局（Global）**：所有流量走当前节点，排错时用；
- **直连（Direct）**：全部不走代理。

日常用规则。打不开某个网站时，先切全局测试：如果全局能开、规则不能，问题在规则；如果全局也不能，问题在节点/网络。

## 5. 开启系统代理

打开顶部的 **系统代理（System Proxy）** 开关。

适合：

- 浏览器；
- 遵守系统代理的桌面应用；
- 大多数日常网页访问。

注意：

- 系统代理不处理 UDP；
- 游戏、部分命令行工具、部分桌面应用可能不遵守系统代理；
- 默认混合端口通常是 `7897`，端口被占用会导致代理失败。

验证：

```bash
curl -I https://www.example.com
```

如果浏览器能访问、命令行不能，通常就是“没有读取系统代理”，需要 TUN 或手动环境变量。

## 6. 开启 TUN（需要时）

TUN 模式创建虚拟网卡，通过路由接管流量，能处理 TCP/UDP，适合：

- 命令行工具；
- 游戏；
- 不遵守系统代理的应用；
- 需要全局透明代理的场景。

开启前确认：

1. 服务模式已安装；
2. 没有其他 VPN/加速器同时运行；
3. 系统防火墙允许 Mihomo 内核；
4. 你接受它可能修改系统 DNS/路由。

打开 **TUN 模式** 开关，等待内核重启。首次开启可能要求管理员权限。

!!! warning "TUN 不是越多越好"
    如果你只用浏览器，系统代理通常够用。TUN 会影响全系统流量，和公司 VPN、虚拟机网络、游戏加速器冲突的概率更高。

## 7. 验证是否生效

### 浏览器

访问一个可以显示出口 IP 的网站，确认 IP 与所选节点地区一致。

### 命令行

```bash
# 查看出口 IP
curl -s https://api.ipify.org

# 检查 DNS
nslookup www.example.com
```

如果命令行仍然显示本地 IP：

- 系统代理没被命令行读取；
- 需要设置 `HTTP_PROXY` / `HTTPS_PROXY`；
- 或开启 TUN。

### 查看规则命中

打开 **连接（Connections）** 页，访问一个网站，观察连接：

- 命中了哪条规则；
- 走了哪个代理组/节点；
- 上传/下载流量；
- 是否有失败/拒绝。

这是排查“为什么这个网站走了直连/代理”的最快方式。

## 8. 更新订阅

订阅会按间隔自动更新，也可以右键 profile 手动更新。

更新后：

- 节点列表可能变化；
- 规则可能被服务商调整；
- 你手动编辑的规则/节点不会随订阅更新丢失（Clash Verge Rev 的编辑节点/规则会单独保存）；
- 扩展配置/脚本会重新应用。

如果更新后出问题，先切回上一个配置或备份，再对比规则。

## 9. 最短检查清单

- [ ] 订阅导入成功
- [ ] 选中了正确的 profile
- [ ] 节点延迟测试正常
- [ ] 路由模式为“规则”
- [ ] 系统代理已开，或 TUN 已开
- [ ] 浏览器出口 IP 正确
- [ ] 命令行按需配置了代理或 TUN
