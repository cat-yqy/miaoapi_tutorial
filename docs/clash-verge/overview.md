# Clash Verge Rev 功能全景

Clash Verge Rev 是 [Clash Verge](https://github.com/zzzgydi/clash-verge) 的延续项目，一个基于 Tauri 的 **Mihomo（Clash Meta）图形客户端**。它把订阅、节点、规则、系统代理和 TUN 虚拟网卡集中到一个桌面界面里，支持 Windows、macOS 和 Linux。

!!! warning "它只是客户端，不提供节点"
    Clash Verge Rev 本身不提供代理服务器、机场订阅或 VPN 服务。你需要自己有订阅链接、自建节点或本地配置文件。软件不会凭空让你“能访问外网”。

## 它解决什么问题

| 问题 | Clash Verge Rev 的做法 |
| --- | --- |
| 手动编辑 YAML 太麻烦 | 图形化导入订阅、选择节点、查看规则 |
| 浏览器能代理，命令行/游戏不行 | 系统代理 + TUN 两种入站模式 |
| 不同网站要走不同线路 | 规则模式、代理组、GEOSITE/GEOIP/进程规则 |
| 多个订阅要合并 | 多配置、扩展配置、扩展脚本 |
| 想给局域网其他设备用 | 允许局域网 + 混合端口 |
| 配置丢了要重来 | WebDAV 备份/同步、配置导出 |
| 想看流量和延迟 | 节点测速、连接列表、流量图、日志 |

## 核心组件

### Mihomo 内核

Clash Verge Rev 内置 [Mihomo](https://github.com/MetaCubeX/mihomo)（Clash Meta）内核，负责真正建立连接、解析规则和应用 DNS。

可以在设置里切换稳定版或 Alpha 内核。Alpha 有新特性，但稳定性较差，日常使用建议稳定版。

### 配置（Profile）

一个配置通常是一份 YAML，包含：

- `proxies`：节点；
- `proxy-groups`：代理组（手动选择、自动选择、故障转移等）；
- `rules`：分流规则；
- `dns`：DNS 设置；
- `tun`：虚拟网卡设置。

订阅导入后，Clash Verge Rev 会把它保存为本地 profile，并按你的设置生成最终运行配置。

### 系统代理 vs TUN

这是两个不同的“入站”模式：

| 模式 | 原理 | 能代理什么 | 限制 |
| --- | --- | --- | --- |
| **系统代理** | 修改操作系统/环境中的代理设置 | 遵守系统代理的浏览器和桌面应用 | 不代理 UDP；不遵守系统代理的程序无效 |
| **TUN 模式** | 创建虚拟网卡，通过路由接管流量 | 大多数 TCP/UDP 流量，包括命令行、游戏 | 需要服务模式/管理员权限；可能和 VPN、加速器冲突 |

### 服务模式

TUN 需要创建虚拟网卡和修改路由。服务模式会安装一个特权后台服务，由它拉起内核，这样你不必每次以管理员身份运行整个 GUI。

- Windows 和 macOS 推荐安装服务模式；
- 服务安装失败时，应用可能退回普通/Sidecar 模式；
- TUN 不可用时，优先检查服务模式状态。

### 规则 / 全局 / 直连

这是“出站”模式：

| 模式 | 行为 |
| --- | --- |
| **规则** | 按配置中的规则逐条匹配，决定直连、代理还是阻断 |
| **全局** | 所有流量走当前选中的代理组/节点 |
| **直连** | 所有流量不走代理 |

日常建议用**规则模式**。只有排查问题或特殊场景才用全局/直连。

## 主要功能

- 内置 Mihomo 内核，可切换稳定/Alpha；
- 订阅链接、订阅配置、URL Schemes、本地文件导入；
- 配置合并（扩展配置）和 JavaScript 扩展脚本；
- 可视化节点、代理组、规则编辑；
- 系统代理和 TUN；
- 节点延迟测试、连接列表、流量统计、日志；
- 允许局域网、IPv6、统一延迟、进程匹配；
- WebDAV 备份和同步；
- 自定义主题、托盘图标、CSS 注入；
- 开机自启、静默启动、托盘菜单；
- 复制命令行代理环境变量；
- 链式代理（v2.4.5+）；
- 自动更新订阅、Geo 数据和应用。

## 适用与不适用

**适合：**

- 已有订阅或自建节点，需要一个稳定的桌面客户端；
- 需要规则分流、按应用/域名/IP 选择线路；
- 需要 TUN 处理命令行、游戏或 UDP；
- 需要给局域网设备提供代理入口；
- 想用图形界面管理多份配置。

**不适合：**

- 没有任何节点/订阅，指望软件自带“免费网络”；
- 需要匿名性保证或对抗性安全模型；
- 在禁止此类工具的网络/组织环境中使用；
- 完全不想理解代理、DNS 和规则，只想一键全自动。

!!! note "合规提醒"
    请确保你的使用符合所在地法律法规、组织网络政策和所使用服务的条款。本文只讨论客户端的技术配置。

本文以 **Clash Verge Rev v2.5.8**（2026-10-09 发布）为参考。

| 平台 | 支持情况 |
| --- | --- |
| Windows 10/11 | x64、arm64；不再支持 Windows 7 |
| macOS | 12 及以上；Intel、Apple Silicon |
| Linux | x64、arm64；deb/rpm/AUR 等 |

界面和选项会随版本变化；遇到不一致时，以当前客户端和[官方文档](https://clash-verge-rev.github.io/)为准。
